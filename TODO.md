# Chatbot com Inteligência Artificial

## Objetivo

Desenvolver uma aplicação web capaz de receber perguntas do usuário e gerar respostas utilizando uma Inteligência Artificial por meio de uma API.

## Descrição

Nesta atividade, vocês deverão desenvolver um chatbot com Inteligência Artificial, integrando uma aplicação web a um serviço de IA.

O usuário deverá digitar uma mensagem na interface da aplicação.  Essa mensagem será enviada ao backend, que será responsável por realizar a comunicação com a API de Inteligência Artificial e retornar a resposta para o usuário.

## Requisitos mínimos

A aplicação deverá possuir:

1. Um campo para o usuário digitar sua mensagem;
2. Um botão para enviar a pergunta;
3. Integração entre frontend e backend;
4. Integração do backend com uma API de Inteligência Artificial;
5. Exibição da resposta gerada pela IA;
6. Uma interface simples e organizada.

## Tecnologias

Sugestão de tecnologias:

- **Frontend:** React;
- **Backend:** Python + Fast API;
- **IA:** API de um modelo de Inteligência Artificial;
- **Comunicação:** API REST utilizando JSON.

## Resultado esperado

Ao final da atividade, deverá ser possível conversar com o chatbot através da aplicação desenvolvida e receber respostas geradas dinamicamente pela Inteligência Artificial.
